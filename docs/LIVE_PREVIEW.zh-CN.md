# 后台实时预览

打开 `/admin/globals/site-settings` 或 Website content 中的内容，使用保存按钮旁的眼睛图标展开 Live Preview。首次进入默认展开；之后沿用个人的开关状态。

- 左侧输入，右侧即时显示，无需保存草稿或发布。
- 后台右上角 Locale 切换中文和英文。
- 预览工具栏可选择手机（390）、平板（768）、桌面（1440）或自适应宽度。
- Website settings 的预览页下拉框可查看首页、联系信息和资质说明；邮箱和电话同时显示在页脚。
- Website content 使用正式网站的详情组件，支持标题、简介、章节、图片和下载文件。新增内容尚未保存时也可以预览。
- 预览内的链接不会跳出当前文档；查看其他文档请从后台选择。

未保存输入仅存在于浏览器预览中。Website settings 点击 Save 后才影响公开网站；Website content 需要发布才能公开。实时预览本身不执行写入，也未开启自动保存。

`/live-preview/zh` 和 `/live-preview/en` 要求后台登录，禁止搜索引擎收录且不缓存。公开页面继续执行已发布内容筛选。

实现使用与 Payload 同版本的 `@payloadcms/live-preview-react`，通过表单消息更新组件状态。首页和详情页与正常网站共用组件，不需要刷新服务器或保存文档。
