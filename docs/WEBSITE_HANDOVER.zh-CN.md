# 匡集官网首版操作说明

## 在现有 Codespaces 更新

在原运行终端按 Ctrl+C 停止旧服务，然后执行：

```bash
git pull --ff-only
pnpm install --frozen-lockfile
pnpm generate:importmap
pnpm payload run scripts/seed-content.ts
pnpm dev
```

保持 3000 端口 Private，点击 Ports 中的浏览器图标。打开 `/zh` 或 `/en`，后台为 `/admin`。种子脚本只添加缺失内容，不覆盖手工修改；正式网站不要重复导入已主动删除的默认内容。

## 后台编辑

- **Website content**：事业部、产品、行业、案例、技术资料、资质共用内容模型。选择 kind、填写英文短链接 slug，然后分别切换中文与英文编辑。
- **Sections**：正文段落，可增加、调整顺序和删除。
- **Image / Download**：关联图片或 PDF。媒体默认私有；审核可公开后勾选 Media 中的 Approved for public website。
- **SEO**：分别填写中文、英文标题和描述。
- 保存草稿不会公开；发布后前台按语言读取内容。英文未填写时不会用中文冒充英文。
- **Website settings**：管理员设置首页主标题、介绍、电话、邮箱、地址及证书说明。留空的联系方式不会显示。
- **Inquiries**：查看真实保存的项目需求、来源参数并调整跟进状态。当前没有发送邮件通知，需要提供业务邮箱及邮件服务后接入。
- **Users**：首位注册用户为管理员，可创建编辑账号；编辑不能创建用户或修改全局设置。

旧版后台创建的账号如没有管理员权限，可在数据库备份后由维护人员核实账号并迁移角色；不要开放后台注册绕过权限。

## 已实现

双语首页、三大事业部、五类产品/服务、六个行业方案、三篇需求准备指南、资质与关于页面、可扩展案例、联系表单、隐私说明、移动菜单、语言对应切换及产品搜索筛选。

表单包含服务端校验、来源记录、蜜罐、基础频率限制和重复提交识别。失败不会清空表单。线索在数据库保存成功后才显示成功。

页面使用本地 Logo、工程概念示意与本地系统字体，没有把示意图当作实际工厂或项目照片。合作目标名单未用作客户背书。

## 内容与数据

Codespaces 自动使用 CMS；其他环境设置 CONTENT_SOURCE=cms 才使用数据库内容。CONTENT_SOURCE=static 可用于不连接数据库的版式预览，不能接收真实询盘。CMS 模式查询失败不公开草稿，也不把已撤下内容恢复成默认文案。

默认内容在 src/lib/content.ts，导入后以 CMS 发布内容为准。真实项目案例、证书扫描件、产品参数、电话邮箱和地址仍需补充。

## 正式上线前

1. 确定正式域名、生产托管和数据库，配置 HTTPS。
2. 设置 SITE_ENV=production、CONTENT_SOURCE=cms、正确的 NEXT_PUBLIC_SERVER_URL 和独立 PAYLOAD_SECRET。
3. 执行经过审核的数据库迁移，生产环境禁用自动 schema push。
4. 媒体迁移到持久对象存储，配置数据库及媒体备份并验证恢复。
5. 完成联系方式、证书有效期与范围、挂牌市场、中英文文案审核。
6. 按实际托管区域、运营方式和保留期限完善隐私说明；确定第三方统计与广告方案后再接入必要的同意机制。
7. 配置边缘防滥用措施。基础限流不替代生产网关；反向代理须覆盖客户端伪造的转发头。
8. 验证正式域名的 sitemap、robots、canonical、hreflang，提交搜索资源平台。
9. 当前询盘来源统计保存在后台；广告平台、CRM及邮件通知尚未接入。

开发预览通过 robots、页面 metadata 和 HTTP 头阻止收录。只有正式环境才开放 robots 与 sitemap。
